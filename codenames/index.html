How to play / rules

How to play (everyone in the same room)

  • Split into two teams: Red and Blue. Each team picks one Spymaster; everyone else is a Guesser.
  • One phone is "The Board" — set it in the middle of the table so all the guessers can see the word grid. Whoever set it up picks one or more languages (pick more than one to mix words from all of them onto the same board) and taps Start Game.
  • The Board screen shows a short Game Code. Each Spymaster opens this same page on their own phone, chooses "A Spymaster", types in that code, and privately sees which words belong to which team — no need to hide anything from guessers, and no internet connection required to sync.
  • The spymaster gives a one-word clue plus a number, e.g. "OCEAN — 2". Say it out loud, or type it into the Board's clue box so everyone can see it.
  • Guessers tap words on the Board they think match the clue. Guessing your own team's color lets you keep guessing. Guessing neutral (tan) or the other team's color ends your turn. Guessing the black Assassin card loses the game instantly for your team.
  • First team to reveal all of their own words wins.
  • Only one phone? The Board also has a "Reveal Key" button as a fallback — spymasters huddle around it while guessers look away, then hide it again.
